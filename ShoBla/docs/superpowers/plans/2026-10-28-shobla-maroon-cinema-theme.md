# Shobla Maroon Cinema Theme

## Goal
Apply the uploaded Shobla Multiplex reference aesthetic across the entire site: deep maroon as the dominant background, warm yellow/gold accents, and creamy text/panels. Keep the existing five sections and imagery while making them feel like one premium hospitality brand.

## Files
- `style.css`: replace the current mixed ivory/wine palette with a unified maroon canvas, cream typography, gold rules, and maroon-toned cards.
- `index.html`: preserve existing sections and image sources.

## Visual rules
- Dominant background: dark burgundy/maroon across every section.
- Primary text: warm cream/ivory.
- Accent: muted cinema-style yellow/gold for labels, dividers, borders, and CTAs.
- Secondary surfaces: slightly lighter maroon, never white/cream card backgrounds.
- Images: framed with thin warm-gold borders and generous spacing.
- Typography: large editorial serif headings, compact uppercase sans-serif labels.
- Avoid animations, transitions, media queries, and dashboard-like UI.

## Verification
- HTML parses successfully.
- Exactly one stylesheet remains linked.
- No `@media`, `transition`, or `animation` declarations.
- Local page returns HTTP 200.
- No unintended CSS variables from the previous ivory palette remain.
